3. How to use

  1. Install the official ExchangeOnlineManagement module if needed: Install-Module ExchangeOnlineManagement -Scope CurrentUser.
  2. Open PowerShell and connect using Connect-ExchangeOnline with an authorized administrator account.
  3. Review the generated script before running it. Some reports require Exchange administrator roles and may take time in large tenants.
  4. Use Disconnect-ExchangeOnline -Confirm:$false when finished.

Exchange Online mailbox permission troubleshooting

Use this free PowerShell generator to inspect direct permissions on Exchange Online shared mailboxes and calendars. Choose Mailbox Full Access to see who can open a mailbox, Mailbox Send As to see who can send as the mailbox, or Calendar folder permissions to review calendar access roles. The combined report brings these checks together for one mailbox.

Full Access vs Send As permissions

Full Access allows a delegate to open and manage mailbox contents, but does not automatically grant Send As. Send As is a separate permission that allows messages to appear as though they were sent by the mailbox. Calendar permissions are folder-level permissions and may include roles such as Reviewer or Editor.

Useful Exchange Online PowerShell commands

Typical read-only checks include Get-EXOMailboxPermission for Full Access, Get-RecipientPermission for Send As, and Get-EXOMailboxFolderPermission for calendar access. Connect with the official Exchange Online PowerShell module before running the generated script. Permission results may include group-based or inherited access that requires additional investigation.

Why a permission might not appear

Check that you selected the correct mailbox, that your account has sufficient administrative rights, and that the permission is assigned directly rather than through a group. Calendar folder names can vary by language. The shared mailbox user-access report scans direct Full Access and Send As assignments and does not calculate complete effective access.
