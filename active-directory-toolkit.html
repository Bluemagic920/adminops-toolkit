Active Directory Toolkit

Generate read-only PowerShell reports for on-premises Active Directory.

1. Choose a report

Used only for reports requiring a name.

2. Review the generated script

Requirements: Run on a domain-connected Windows computer with the ActiveDirectory PowerShell module (RSAT), and an account authorized to read the requested directory data. Scripts are read-only. Test before using in production.

3. How to run

Open Windows PowerShell on a domain-connected machine, confirm RSAT Active Directory tools are installed, and run the generated commands with appropriate permissions. Review output for accuracy before making any administrative changes.

This browser app does not connect to your domain, collect credentials, or execute PowerShell.
