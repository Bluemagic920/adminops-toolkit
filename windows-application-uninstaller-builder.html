Windows Application Uninstaller Builder

Generate PowerShell scripts to find installed software and prepare controlled uninstall operations. Review the discovered registry information before removing anything.

Safe by default: The browser only generates code. It never connects to your PC or uninstalls software. Inventory is read-only; uninstall scripts default to preview mode, require an exact application name, and require a second confirmation before execution.

1. Configure your script

Inventory: optional name filter. Uninstall: exact DisplayName required.
EXE uninstall switches differ by vendor. This tool does not guess silent flags, force-delete folders, or use Win32_Product. For EXE installers, it prints the vendor uninstall command for manual review instead of executing it automatically.

2. Review and save

Run generated PowerShell only on systems you administer. Use an elevated PowerShell console for machine-wide uninstall operations; test on a nonproduction device first.

How to create a PowerShell uninstall script for Windows 10 and Windows 11

Use this free script generator to inspect installed software before deciding how to uninstall it. Select Inventory installed applications to generate read-only PowerShell that checks Windows uninstall registry entries. You can filter by application name and display results in PowerShell or export a CSV inventory.

Find an installed application's uninstall command

Windows commonly records software details under HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall and the 32-bit WOW6432Node location. Entries may include DisplayName, UninstallString, and QuietUninstallString. These values are useful when investigating SCCM/MECM application removal or creating a controlled uninstall package.

MSI versus EXE uninstall scripts

For an exact application name with a single MSI product-code match, this builder prepares an msiexec.exe /x command. By default it only previews the uninstall. Execution requires explicitly enabling the option and then typing UNINSTALL when the generated script runs. For EXE-based installers, vendor-specific silent switches vary, so the generated script shows the discovered command for review instead of running it automatically.

Common troubleshooting checks

  • Application not found: Verify the exact DisplayName and whether it was installed for another user or outside the selected registry locations.
  • Multiple matches: Review the application version, publisher, registry path, and product code before choosing a target.
  • Uninstall fails: Review the MSI exit code, installer logs, administrator permissions, and pending reboot requirements. Do not force-delete application directories as a substitute for uninstalling.
  • Deploying with SCCM or Intune: Test the resulting script on a nonproduction device and create separate, reliable detection and verification logic.

This is a browser-based code generator, not a remote uninstaller or an application removal service. The site does not inspect your computer, execute commands, or guarantee silent removal of every installer.
