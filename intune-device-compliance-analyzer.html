AdminOps Toolkit · Application 19

Intune Device Compliance Analyzer

Generate PowerShell reports for Microsoft Intune device compliance, enrollment, management status, and Windows MDM troubleshooting.

Cloud reports use Microsoft Graph. Local diagnostics use Windows PowerShell.
Required for device-name and user-specific reports only.

Before running a generated script

Generated commands are for administrator review and testing. They do not execute in this website. Microsoft Graph reports may expose device or user information; handle output according to your organization's policies.

For cloud reports, install the Microsoft.Graph PowerShell modules if needed, and sign in with an account permitted to read Intune data. Local diagnostics must run on the affected Windows device. Some commands require elevated PowerShell.
