Windows Services Manager

Generate Windows PowerShell 5.1-compatible service diagnostics and carefully reviewed service actions.

Use the Windows service name, not its display name. Only letters, digits, underscores, hyphens and periods are accepted.

Generated PowerShell

Select a task and click Generate PowerShell.

Review scripts before running. Some diagnostics require an elevated PowerShell session. Starting or restarting services may interrupt applications. Do not paste credentials or secrets into this tool; all generation happens in your browser.
