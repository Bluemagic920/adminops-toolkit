SCCM Query Builder

Create ready-to-review WQL queries for Microsoft Configuration Manager device collections. Choose a query type, enter your criteria, and copy the generated query.

1. Configure your query

Searches inventoried Add/Remove Programs names (both 32-bit and 64-bit inventory classes).
Inventory-dependent queries only find data your site has collected. Confirm the relevant hardware inventory classes are enabled and refreshed before relying on results.

2. Review and export

For device collection membership rules, paste the WQL into a Query Rule in the collection's Membership Rules. Review and test results before deploying anything to a collection.

3. Use in Configuration Manager

  1. Open the Configuration Manager console and go to Assets and Compliance → Device Collections.
  2. Create a new device collection or open the properties of an existing one.
  3. In Membership Rules, add a Query Rule, then choose Edit Query Statement.
  4. Use Show Query Language, replace the WQL with the generated query, and save.
  5. Preview or validate membership in your environment before using the collection for deployments.

This application generates text only. It does not connect to your SCCM environment, run queries, or change collections.

SCCM WQL query examples and troubleshooting

Use this free browser-based builder to create Microsoft Configuration Manager (SCCM/MECM) device collection queries. Choose a common scenario, enter your filter, then review and copy the WQL for your own environment.

Find computers with installed software

Select Installed software (ARP inventory) and enter part of an application display name, such as Roxio. The builder checks both the standard and 64-bit Add/Remove Programs inventory classes. Results depend on hardware inventory being enabled and up to date; software that does not appear in those classes may not be found.

Find Windows 11 devices or computers by name

Select Operating system caption to filter inventoried operating system names, or Computer name to find devices matching a naming convention. Confirm your inventory data and test the query in Configuration Manager before using it for deployments.

Query existing collection membership

Use Devices in an existing collection with a collection ID, not the display name. You can also select Configuration Manager client installed to identify resources reporting the client flag.

Why might a query return no devices?

Common causes include stale or disabled hardware inventory, a mismatched application display name, an incorrect collection ID, or querying a class that does not contain the expected data. The generated query is a starting point, not a live inventory check.
