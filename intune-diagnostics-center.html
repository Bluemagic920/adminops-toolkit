Common Microsoft Intune troubleshooting tasks


Use the tabs above to investigate a specific Windows device. This browser-based helper generates commands and checklists; it does not connect to your tenant or diagnose a live Microsoft service outage.


Intune enrollment errors and enrollment restrictions


When a Windows device cannot enroll, check Intune licensing, MDM user scope, device enrollment restrictions, and the exact enrollment error. The Guided Diagnostics tab provides a structured enrollment checklist.


Device compliance and MDM sync failures


If a device is marked noncompliant or stops checking in, compare its last check-in with the policy's individual setting results. Review the device's work or school account and the EnterpriseMgmt scheduled tasks before changing enrollment state.


DeviceManagement-Enterprise-Diagnostics-Provider/Admin events


Windows records many MDM enrollment and policy events in the Microsoft-Windows-DeviceManagement-Enterprise-Diagnostics-Provider/Admin log. Use the Command Builder tab to generate a read-only PowerShell or Command Prompt query for recent events, then correlate the event IDs with the device's symptoms.


Microsoft Entra join and co-management


Use dsregcmd /status to inspect device join and registration indicators. For Configuration Manager co-managed devices, confirm workload ownership before changing policy or enrollment settings.



How to inspect DeviceManagement-Enterprise-Diagnostics-Provider/Admin


Open Event Viewer and navigate to Applications and Services Logs → Microsoft → Windows → DeviceManagement-Enterprise-Diagnostics-Provider → Admin. Look for events near the failed enrollment or policy sync. Capture the event ID, timestamp, error code, and relevant message before making changes. In the Command Builder, select MDM event logs to generate a read-only query.


Using MdmDiagnosticsTool.exe to collect MDM logs


Windows includes MdmDiagnosticsTool.exe for collecting mobile device management diagnostic information. On an authorized Windows device, an administrator can review the available options with MdmDiagnosticsTool.exe /?. Follow current Microsoft documentation for supported collection commands and securely handle exported logs, which may contain device or organization information. This page does not execute the collection tool.


Check Windows device registration with dsregcmd


Run dsregcmd /status locally to inspect join and registration indicators. Interpret AzureAdJoined, DomainJoined, and WorkplaceJoined according to the intended device configuration; being joined to Microsoft Entra ID does not, by itself, prove successful Intune enrollment.


Is Microsoft Intune down today?


If multiple devices start failing simultaneously, check your tenant's Microsoft 365 admin center Health → Service health information and your own network or authentication dependencies. This page provides device-level troubleshooting guidance, not real-time Intune outage information.
