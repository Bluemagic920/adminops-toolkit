Generated PowerShell

Select an investigation type, then click Generate PowerShell.
Safety: Generated commands only read event logs. They do not repair or delete anything. Review scripts before running. Security logs may require elevation. A matching Event ID alone does not prove the cause of an incident.

Common Event IDs

41 — Kernel-Power

System restarted without a clean shutdown.

6008 — EventLog

Previous shutdown was unexpected.

1000 — Application Error

An application fault was recorded.

4625 — Failed logon

Windows recorded an unsuccessful sign-in.

4740 — Account lockout

An account was locked out on the system recording the event.

7031 — Service Control Manager

A service terminated unexpectedly.

Event meaning and availability depend on the log source, Windows version, and audit configuration.
