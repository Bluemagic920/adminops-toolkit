Microsoft 365 Admin Toolkit

Generate reviewable Microsoft Graph PowerShell scripts for common Microsoft 365 administration and reporting tasks. No tenant credentials are entered or stored on this page.

1. Configure your task

Enter the exact Microsoft 365 user principal name.
CSV reports are saved in the folder where you run PowerShell.

2. Review your PowerShell script

Choose a task, enter the user principal name if required, then click Generate PowerShell.
Review before running: Scripts are read-only reporting examples. Run them only in a tenant you administer, verify required Microsoft Graph permissions, and test in a safe environment. Generated reports may contain personal information; store them securely. Microsoft Graph PowerShell must be installed separately.

Before you run a script

Open PowerShell, install the Microsoft Graph module if your environment permits, and connect with an account authorized for the requested report. The generated script includes its own Connect-MgGraph command and the least-privileged delegated scopes appropriate to the selected example where practical. Tenant policies may require admin consent.

Install-Module Microsoft.Graph -Scope CurrentUser

Use the latest supported Microsoft Graph PowerShell SDK. The toolkit generates commands but does not connect to Microsoft 365 itself.
