Application #27 · Windows Security

Windows Certificate & TLS Analyzer

Generate ready-to-review PowerShell diagnostics for certificate stores, expiration, trust chains, TLS protocols, HTTPS endpoints, and Schannel errors.

Choose a diagnostic and click Generate PowerShell.

Safety: These are read-only diagnostic templates except for the optional CSV export, which writes a local file. The HTTPS certificate inspection deliberately accepts a server certificate for diagnostic display only; it does not establish trust. Review scripts before running, and use elevated PowerShell only when necessary.
